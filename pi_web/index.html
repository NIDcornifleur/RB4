Inclinaison : — Vitesse : 0 % Virage : 0 %

Déplacement

Glissez le rond bleu : haut = avancer, côtés = tourner. Relâché, le robot s'arrête. Au clavier : flèches ou W A S D, barre d'espace = arrêt.

Gyroscope

Robot couché et immobile. La DEL du MM1 s'allume 3 secondes ; si le robot bouge, la mesure recommence. À faire si le robot part toujours du même côté alors que l'angle semblait bon. Le résultat s'affiche sous les réglages.

Raspberry Pi

Extinction propre du Pi avant de couper la batterie. Le MM1 continue de tenir l'équilibre sur place.
